# Generador de Códigos QR Dinámico 📱

Una aplicación web interactiva, moderna y ejecutada completamente en el navegador para generar códigos QR personalizados. Ideal para compartir de manera rápida enlaces, accesos Wi-Fi, información de contacto y más.

## 🚀 Características

* **Múltiples tipos de datos soportados:**
  * 🔗 Texto o Enlaces (URLs)
  * 📶 Credenciales de Red Wi-Fi
  * 📧 Correos Electrónicos
  * 📞 Números de Teléfono
  * 💬 Mensajes SMS
* **Personalización Avanzada:**
  * 🎨 Selector de colores para el patrón (frente) y el fondo.
  * 💠 Diversos estilos de patrones (Cuadrado clásico, Puntos, Redondeado, Extra redondeado, Elegante).
  * 🔲 Diferentes formas para las esquinas del QR.
* **Branding Integrado:** Opción para cargar un **Logo** (PNG, JPG, SVG) que se incrustará automáticamente en el centro del código QR.
* **Tamaño Ajustable:** Control deslizante para ajustar la resolución del código QR generado (de 150px a 1000px).
* **Exportación Fácil:** Descarga tu código QR generado con un solo clic en formatos **PNG, JPG o SVG**.
* **100% Client-side:** Sin necesidad de backend. Los códigos se generan directamente en tu navegador garantizando privacidad y rapidez.

## 🛠️ Tecnologías Utilizadas

* **HTML5, CSS3, JavaScript (Vanilla)**
* [QR Code Styling](https://github.com/kozakdenys/qr-code-styling) - Librería principal para el renderizado del código QR usando Canvas/SVG (Cargada vía CDN).

## 📦 Instalación y Uso

Dado que la aplicación está construida con tecnologías web estándar y no requiere compilación ni un entorno de servidor complejo, instalarlo y ejecutarlo toma solo unos segundos:

1. **Clona este repositorio:**
   ```bash
   git clone https://github.com/tu-usuario/nombre-del-repo.git
   ```
2. **Abre el archivo** `index.html` directamente en tu navegador web favorito (Chrome, Firefox, Safari, Edge, etc.).
3. *(Opcional)* Si prefieres usar un servidor local, puedes usar extensiones como *Live Server* en VS Code o Python:
   ```bash
   python -m http.server 8000
   ```
